# Guessing Game

A small Rust command-line game where the player tries to guess a random number.

The game gives feedback such as "too low" or "too high" and keeps track of the number of attempts until the player guesses correctly. It is a simple project for learning Rust basics, input handling, randomness, and CLI output styling.

## Features

- Random number generation
- User input prompt
- Warm/cold hints during play
- Colored terminal output

## Run the game

```bash
cargo run
```
